# Student Management System (C++)

A small console application in C++ to manage student records. Built to practice structs, arrays, file-free data handling, and basic menu-driven programs.

## Features

- Add a student (name, ID, GPA)
- List all students
- Search for a student by ID
- Show the top student by GPA

## How to run

You need a C++ compiler like g++:

```bash
g++ student_management.cpp -o students
./students
```

## What I learned

- Working with structs and arrays of records
- Building a menu loop with input validation
- Searching and comparing records
- Organizing code into functions
